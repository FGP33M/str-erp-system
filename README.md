# STR ERP SYSTEM (Phase 1)
> ระบบ ERP ร้านอะไหล่ & ฮาร์ดแวร์ • เชื่อมต่อ Google Sheets 3 ไฟล์ • รองรับ Cloudflare Pages / Workers

---

## 🌟 ฟีเจอร์ที่พัฒนาใน Phase 1

1. **ระบบล็อกอิน & สิทธิ์ผู้ใช้งาน (RBAC):**
   - ตรวจสอบชื่อผู้ใช้และรหัสผ่านจากไฟล์ **`ERP_AUTH`**
   - บันทึกประวัติการล็อกอิน วันที่/เวลา, IP, สถานะ ลงแท็บ **`Login_Logs`** อัตโนมัติ
   - **การแบ่งสิทธิ์:**
     - **พนักงาน (Staff):** ค้นหาสินค้าได้ **ซ่อนราคาทุนถาวร** (API ตัดข้อมูลออก ป้องกันการดูใน Network tab)
     - **พนักงานอาวุโส (Senior Staff):** ค้นหาสินค้า (ซ่อนราคาทุน)
     - **ผู้จัดการ (Manager):** **เห็นราคาทุน**, กำไรส่วนต่าง (Margin), รีเฟรชแคชสินค้าได้
     - **ผู้ดูแลระบบ (Admin):** สิทธิ์ครบทุกอย่างในระบบ

2. **หน้าเมนูหลัก (Dashboard):**
   - แสดงการ์ดผู้ใช้งาน, ป้ายสิทธิ์สีเฉพาะตำแหน่ง
   - เมนูเข้าสู่ **"ระบบค้นหาสินค้า"**
   - เมนูเตรียมความพร้อมสำหรับ Phase 2 (บันทึกบิลส่งของเขียนมือ, บันทึกรายรับ, บันทึกการซื้อ)

3. **ระบบค้นหาสินค้าอัจฉริยะ (Product Search):**
   - ค้นหาสินค้าจริง **3,000 รายการ** ได้แบบ Real-time รวดเร็วทันใจ
   - ค้นหาได้จาก: ชื่อสินค้า, บาร์โค้ด, รหัสอะไหล่, ร้านค้า, หรือตำแหน่งชั้นวาง
   - กรองตามร้านค้า / ผู้จำหน่ายได้
   - **ตัวถอดรหัสฟิลด์ "รายละเอียด" อัตโนมัติ:**
     - 📦 **หน่วยนับ/แพ็ค:** เช่น `ตัว (แพ็ค 1)`, `หลอด (แพ็ค 10)`
     - 📊 **สต็อกสูงสุด (F):** เช่น `Max: 3`
     - 📍 **ที่เก็บ/ชั้นวาง (L):** เช่น `ชั้น A`, `ชั้น A01010202` (ไฮไลต์สีฟ้าเด่นชัดเพื่อให้หยิบของได้เร็ว)
     - 📅 **รับเข้าล่าสุด (D):** เช่น `18/3/67`, `24/12/61`
     - 🏷️ **รหัส/หมายเหตุ (C):**

## 💻 วิธีเปิดใช้งานบนเครื่องคอมพิวเตอร์ (Local)

เปิด Command Prompt หรือ PowerShell ในโฟลเดอร์นี้ แล้วสั่ง:

```bash
node server.js
```
เปิดบราวเซอร์ไปที่: **`http://localhost:3000`**
